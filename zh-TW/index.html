Step 0 · 只準備一次

開始前準備

  1. 安裝 Copilot CLI。npm i -g @github/copilot（1.0.103）。課程的 Python SDK 要靠 copilot 命令調模型；只裝 App 不夠。CLI 與 App 1.1.32 共用登入，不用再登入一次。
  2. 建 Python 環境。python3.12 -m venv ~/.venvs/hol_ghc_app，用公共 PyPI 裝 requirements.txt，再 playwright install chromium。課程原文用的是微軟的 packagefeedproxy 映象，公網可以訪問（2026-10-30 實測 npm / PyPI 均返回 200）；本次改用公共源只是個人選擇，按原文命令安裝同樣可以。venv 放在 OneDrive 外，避免同步。
  3. 確認模型。python tools/probe.py 的模型列表裡有 gpt-6-luna，才繼續；沒有就先解決帳號權限，不換模型。
  4. 在 App 裡選專案和工作區。App 裡的 hol_ghc_app 專案指向 ~/Projects/hol_ghc_app。新建會話時把 Workspace 從 New worktree 改成 Current checkout，對應課程說的「本地資料夾會話」。
  5. 選模式和模型。輸入框下方選 Autopilot，模型在 More models 裡選 GPT-6 Luna。不要停在 Auto。
  6. 把工具權限設為 Approve all。點 Autopilot → Tool permissions → Approve all。不改的話，Autopilot 下沒人點批准，所有命令都會被拒（見 Lab 1 第一輪）。

Lessons

踩坑與取捨

最關鍵

Autopilot 要配 Approve all

工具權限預設是 Always ask。Autopilot 下沒人點批准，命令全部被拒，Agent 只能讀程式碼。

取捨：Approve all 讓 Agent 在本倉庫裡不經確認就跑命令。這是課程「連續執行」的前提；靠提示詞裡的「只修改 LabN/Code、不要提交」劃邊界。

倉庫信任

選 Skip for now

倉庫裡沒有 hooks、MCP 或擴充功能配置，不需要信任它；信任會讓這些配置以後都能自動執行程式碼。

注意：不信任時 App 會提示「Tool permissions limited」，但在 Approve all 下命令能正常執行。

鎖屏

App 後臺照跑，介面操作要解鎖

向日葵斷開後 Mac 立即鎖屏，取不到 App 視窗。解法：解鎖時一次性把 Lab 2/3/4 派出去，三個會話改的是不同目錄，可以並行；提示詞加「不要停下來提問」。

代價：執行中途的進度截圖少了，只有「發出時」和「完成後」兩張。

工作區

Current checkout 會切回 main

預先開的 run 分支被 App 切回了 main，改動停在 main 的工作區裡，沒有提交。

要留檔的話，先 git switch -c 帶著改動開分支再提交。

依賴源

映象和公共源都能用

README 用的是 packagefeedproxy.microsoft.io。本次 PyPI 和 npm 都改用了公共 registry，版本保持鎖定，結果一致。

更正：手冊初版寫「外部帳號連不上這個映象」，當時沒有驗證。2026-10-30 實測公網可訪問，上游課程的 Pages 工作流也在用它。

副作用

App 改寫了 Lab2/README.md

Agent 把 README 裡的命令改成了本機 venv 路徑和公共源。適合本機復現，不適合合回課程倉庫，提交前要回退這個檔案。

系統彈窗

Python 請求「本地網路」權限

啟動本地服務時 macOS 會彈出這個詢問。實驗只用 127.0.0.1，選「不允許」也不影響。

規劃提問

Plan 模式會停下來問關鍵選擇

Lab 2 規劃時，App 問旁白用固定稿還是 SDK 生成。這正是 Plan 的價值：影響實現的決定由人來做。
