Step 0 · 只准备一次

开始前准备

  1. 先做工具版本预检。运行 python3 --version、copilot --version、node --version、npm --version、ffmpeg -version 与 ffprobe -version。课程要求 Python 3.11+、Copilot CLI；Lab 2 视频还需要 Node.js 22+ 与 FFmpeg。若 CLI 缺失，可按课程 README 用 npm i -g @github/copilot 安装；其他缺失工具也应先安装再继续。
  2. 在虚拟环境中安装 Python 依赖。在课程根目录运行 python3 -m venv .venv，激活环境后用 python -m pip --version 确认 pip 指向 .venv，再按 README 执行 python -m pip install -r requirements.txt --index-url https://packagefeedproxy.microsoft.io/pypi/simple/ 和 python -m playwright install chromium。Windows PowerShell 使用 py -m venv .venv 与 .\.venv\Scripts\Activate.ps1。不要对系统 Python 直接运行 pip install，也不要用 --break-system-packages 绕过 PEP 668。
  3. 确认模型。python tools/probe.py 的模型列表里有 gpt-6-luna，才继续；没有就先解决账号权限，不换模型。
  4. 在 App 里打开课程文件夹。从 Sessions 旁的 + 添加或打开本地 hol_ghc_app 文件夹，确认其中有 README.md 和 Lab1–Lab4。Project 是 App 内的会话组织入口，不等于克隆仓库，也不会代替添加本地文件夹。
  5. 核对运行位置和模型。新会话默认可能是 New worktree；课程要使用当前本地克隆，必须显式改为 Current checkout。本次准备环境选择 This computer、GPT-6 Luna · Medium，并关闭 Copilot Fusion。不要停在 Auto。
  6. 检查当前 Tool permissions。发送任务前先查看当前会话的权限选项和作用；Always ask 会逐项等待批准，Assisted 可减少部分确认，Approve all 允许命令和工具不经逐项确认运行。按可信目录和组织策略选择，不要关闭 macOS 或其他系统安全保护。

Lessons

踩坑与取舍

权限说明

按会话确认 Tool permissions

2026-11-12 的历史记录中，Autopilot 配合 Always ask 时，因没有交互批准而被拒绝；这是当时的执行环境观察，不是要求关闭系统安全。

Always ask、Assisted、Approve all 影响 Copilot 运行工具时的确认方式。Approve all 会允许该会话不经逐项确认运行命令；只在可信目录和合适策略下使用，并保持 macOS 等系统安全保护开启。

仓库信任

仓库信任与工具权限是独立控制

历史截图曾显示 Skip for now；首次发送时跳过仓库信任会导致 Autopilot 工具调用被拒绝。选择 Always trust 前应确认仓库来源并检查其配置、hooks 和扩展；此选项允许仓库配置、hooks、扩展及未来更新执行。

仓库信任与 Tool permissions 是独立控制：后者决定 Copilot 使用工具时的批准方式。只信任你已审查并认可的仓库，不要关闭系统安全保护，也不需要授权无关 MCP 服务。

锁屏

App 后台照跑，界面操作要解锁

向日葵断开后 Mac 立即锁屏，取不到 App 窗口。解法：解锁时一次性把 Lab 2/3/4 派出去，三个会话改的是不同目录，可以并行；提示词加「不要停下来提问」。

代价：运行中途的进度截图少了，只有「发出时」和「完成后」两张。

工作区

Current checkout 会切回 main

预先开的 run 分支被 App 切回了 main，改动停在 main 的工作区里，没有提交。

要留档的话，先 git switch -c 带着改动开分支再提交。

依赖源

镜像和公共源都能用

README 用的是 packagefeedproxy.microsoft.io。本次 PyPI 和 npm 都改用了公共 registry，版本保持锁定，结果一致。

更正：手册初版写「外部账号连不上这个镜像」，当时没有验证。2026-10-30 实测公网可访问，上游课程的 Pages 工作流也在用它。

副作用

App 改写了 Lab2/README.md

Agent 把 README 里的命令改成了本机 venv 路径和公共源。适合本机复现，不适合合回课程仓库，提交前要回退这个文件。

系统弹窗

Python 请求「本地网络」权限

启动本地服务时 macOS 会弹出这个询问。实验只用 127.0.0.1，选「不允许」也不影响。

规划提问

Plan 模式会停下来问关键选择

Lab 2 规划时，App 问旁白用固定稿还是 SDK 生成。这正是 Plan 的价值：影响实现的决定由人来做。
