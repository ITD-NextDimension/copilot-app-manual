Step 0 · Do this once

Setup

  1. Preflight tool versions. Run python3 --version, copilot --version, node --version, npm --version, ffmpeg -version and ffprobe -version. The course needs Python 3.11+ and Copilot CLI; Lab 2 video also needs Node.js 22+ and FFmpeg. If the CLI is missing, install it with the course README's npm i -g @github/copilot command; install other missing required tools before continuing.
  2. Install Python dependencies inside a virtual environment. From the course root run python3 -m venv .venv, activate it, confirm python -m pip --version points into .venv, then follow the README with python -m pip install -r requirements.txt --index-url https://packagefeedproxy.microsoft.io/pypi/simple/ and python -m playwright install chromium. In Windows PowerShell, use py -m venv .venv and .\.venv\Scripts\Activate.ps1. Do not run pip install against system Python or use --break-system-packages to bypass PEP 668.
  3. Confirm the model. Continue only if python tools/probe.py lists gpt-6-luna. If it does not, fix account access first instead of switching models.
  4. Open the course folder in the App. Use Sessions + to add or open the local hol_ghc_app folder, and confirm it contains README.md and Lab1–Lab4. A Project is an App organization view; it is not a clone and does not replace adding the local folder.
  5. Confirm where the session runs and which model it uses. New sessions may default to New worktree; explicitly select Current checkout to work in this local clone. This preparation used This computer, GPT-6 Luna · Medium, and Copilot Fusion off. Do not leave the model on Auto.
  6. Inspect the current Tool permissions setting. Check its selection and effect in the session menu before sending a task: Always ask waits for approval, Assisted can reduce some prompts, and Approve all allows commands and tools to run without per-command approval. Choose based on repository trust and policy; do not disable macOS or other system security protections.
2026-11-25 · SETUP RECORD

Keep the repositories separate

Recommended layout: sibling folders copilot-app-manual/ and hol_ghc_app/ under Demo-GH. From Demo-GH's parent directory, run mkdir -p Demo-GH, then cd Demo-GH, followed by git clone https://github.com/ITD-NextDimension/copilot-app-manual copilot-app-manual and git clone https://github.com/ITD-NextDimension/hol_ghc_app hol_ghc_app. Never run git clone URL . in a non-empty directory. For an existing clone, inspect git status --short --branch and review changes before deciding whether to update. If the documentation repository is already at the Demo-GH root, keep it there, clone the course repo into hol_ghc_app/, and add that path only to the documentation repo's .git/info/exclude.

After the first send, the App may show “Trust this repository?”. Skipping trust will cause Autopilot tool calls to be denied. Before choosing Always trust, verify the repository source and review its configuration, hooks and extensions; this option allows repository configuration, hooks, extensions and future updates to run. Repository trust and Tool permissions are separate controls: trust applies to repository content, while Tool permissions controls approval for Copilot tool use. Trust only repositories you have reviewed and accept; do not disable system security.

If a multi-organization Copilot license reports “Billing setup required” or the home page says usage is blocked, open Copilot features settings, select a Copilot-authorized entity under Usage billed to, then retry; Miruth was selected in this preparation. A credits balance does not mean the user has usable budget, so do not assume every block is a low-credit issue. An unrelated MCP sign-in prompt does not block the local chess app and does not need to be authorized for this lab.

Lessons

Lessons and trade-offs

PERMISSIONS

Check Tool permissions per session

In the historical 2026-11-12 run, Autopilot with Always ask was blocked because no interactive approval was available. That observation is not a recommendation to disable system security.

Always ask, Assisted and Approve all control how Copilot asks before using tools. Approve all permits commands without per-command confirmation; use it only for a trusted folder and when policy allows, while keeping macOS and other system protections enabled.

REPOSITORY TRUST

Repository trust and tool permissions are independent controls

A historical screenshot shows Skip for now; skipping repository trust on first send will cause Autopilot tool calls to be denied. Before choosing Always trust, verify the repository source and review its configuration, hooks and extensions; this option permits repository configuration, hooks, extensions and future updates to run.

Repository trust and Tool permissions are separate controls; the latter governs approval for Copilot tool use. Trust only repositories you have reviewed and accept. Do not disable system security or authorize unrelated MCP services.

SCREEN LOCK

The App keeps working; the UI needs an unlocked screen

The Mac locked as soon as the remote desktop disconnected, and the App window could not be reached. The fix: while unlocked, send Labs 2/3/4 in one go (they change different folders, so they can run in parallel), and add "do not stop to ask questions" to the prompts.

Cost: fewer progress screenshots, only "when sent" and "when done".

WORKSPACE

Current checkout switches back to main

The run branch created beforehand was switched back to main by the App; the changes stayed uncommitted in main's working tree.

To keep them, create a branch with git switch -c first, then commit.

PACKAGE SOURCES

Both the mirror and public registries work

The README uses packagefeedproxy.microsoft.io. This run used the public PyPI and npm registries with pinned versions, with the same results.

Correction: the first version of this manual said the mirror was unreachable for outside accounts, without testing it. On 2026-10-30 it was reachable from the public internet, and the upstream Pages workflow uses it.

SIDE EFFECT

The App rewrote Lab2/README.md

The agent changed the README commands to the local venv path and public registries. Fine for reproducing locally, but it should not go back into the course repository; revert that file before committing.

SYSTEM PROMPT

Python asks for local network access

macOS asks this when the local server starts. The labs only use 127.0.0.1, so choosing "Don't Allow" has no effect on them.

PLAN QUESTIONS

Plan mode stops to ask about key choices

While planning Lab 2, the App asked whether the narration should be a fixed script or generated through the SDK. That is the point of Plan: decisions that shape the implementation are made by a person.
