第 0 章 · 准备环境并认识 App

这一章边准备边认识 App：每装好一样东西，就顺手看清它在 App 里对应哪个按钮。全部做完大约 25 分钟，请在课前完成。做完后，四个 Lab 只需要 App 和一个终端窗口。

0.1 安装并登录 App，确认有 GPT-6 Luna

从 gh.io/app 下载 GitHub Copilot App，用有 Copilot 授权的 GitHub 账号登录。点左上角 New，再点输入框下方的模型按钮（显示为 GPT-6 Luna · Medium 之类），展开 Model。

为什么四个 Lab 都用 GPT-6 Luna。课程代码会检查模型，列表里没有就直接停止，不会悄悄换成别的模型。

检查Model 列表里有 GPT-6 Luna。没有的话，先找管理员解决账号或组织的模型权限，不要换模型继续。
App 功能

模型菜单 Model menu

  • Copilot Fusion：多模型协同，课程中保持关闭。
  • Effort：思考深度，课程用 Medium。越高越慢、消耗越多。
  • Context window：单次会话能记住的上下文长度（本次为 272K）。快满时 App 会自动压缩旧消息。
提示这里的 Copilot 是 GitHub Copilot App，不是 Microsoft 365 Copilot。首页可能弹出促销卡片或更新提示，点关闭即可，课堂中途不要重启 App。

CLI 功能

Copilot CLI 与 Python SDK CLI & SDK

  • Python 的 github-copilot-sdk 不直接连云端：它在后台启动 copilot 命令，通过标准输入输出（stdio）和它对话。所以 CLI 必须装好、登录好。
  • App 和 CLI 共用 ~/.copilot 目录（Windows 为 %USERPROFILE%\.copilot）：会话记录在 session-state/，插件、Skills、扩展也在这里。用 CLI 装的插件，App 不用重启就能看到（Lab 2 会用到）。
  • 课程的 tools/agent.py 给每个会话只开放“完成任务”一个工具，禁止它浏览网页、读写文件或创建子 Agent，并且不在模型不可用时偷偷换模型。

0.6 在 App 添加课程文件夹

在 App 左侧 Sessions 旁点 +，选择 Add local folder or repository，在弹出的“Select folder or repository”里选中 Demo-GH/gh_app_workshop，点 Open。

为什么App 只能改它“打开”的文件夹。打开课程根目录后，Agent 才能读到四个 Lab 的代码。

App 功能

Sessions 与 Projects where sessions live

  • Sessions：按文件夹分组的会话列表。课程的每个 Lab 都从这里的 gh_app_workshop 新开一个会话。
  • Projects：可选的项目分组，不会克隆代码。本课程不需要。
  • 注意：左上角的 New 会开一个不挂文件夹的空白会话（Chat）。每个 Lab 都要从 Sessions 里 gh_app_workshop 的 + 开始，否则 Agent 看不到课程文件。

0.7 设置模式、权限和工作位置

在 New session 里依次检查输入框下方的按钮。

模式（Mode）

点模式按钮（默认显示 Interactive），弹出三种模式。输入框的边框颜色会跟着变：Interactive 灰色、Plan 蓝色、Autopilot 绿色。

工具权限（Tool permissions）

在同一菜单打开 Tool permissions，选 Approve all。

为什么Autopilot 中途不会停下来等人。如果权限是 Always ask，它每次运行命令都没人批准，命令会全部被拒绝，结果只读了文件、什么也没做成。

安全Approve all 允许 Agent 不经确认运行命令。只在课程文件夹和练习数据上使用。

文件夹、Run on、Where to work

为什么New worktree 会为每个会话复制一份独立目录；课程要在你克隆的这一份上直接修改、运行和验收，所以用 Current checkout。

App 功能

三种模式与“模式记忆” modes

  • Interactive：一步一停，适合方向未定时边做边看。
  • Plan：先调研、写计划（plan.md），你批准之前不改任何文件。适合需求模糊、牵涉面广、改错代价高的任务（Lab 2）。
  • Autopilot：边界清楚时连续执行到底（Lab 1、3、4）。
  • 新会话会沿用上一个会话的模式。实跑中 Lab 1 用了 Autopilot，Lab 2 新会话默认就是 Autopilot；Lab 2 用了 Plan，Lab 3 新会话默认就是 Plan。每次发送前看一眼边框颜色。

CLI feature

Copilot CLI and the Python SDK how they connect
