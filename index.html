Step 0 · 只准备一次

开始前准备

  1. 安装 Copilot CLI。npm i -g @github/copilot（1.0.103）。课程的 Python SDK 要靠 copilot 命令调模型；只装 App 不够。CLI 与 App 1.1.32 共用登录，不用再登录一次。
  2. 建 Python 环境。python3.12 -m venv ~/.venvs/hol_ghc_app，用公共 PyPI 装 requirements.txt，再 playwright install chromium。课程原文用的是微软的 packagefeedproxy 镜像，公网可以访问（2026-10-30 实测 npm / PyPI 均返回 200）；本次改用公共源只是个人选择，按原文命令安装同样可以。venv 放在 OneDrive 外，避免同步。
  3. 确认模型。python tools/probe.py 的模型列表里有 gpt-6-luna，才继续；没有就先解决账号权限，不换模型。
  4. 在 App 里选项目和工作区。App 里的 hol_ghc_app 项目指向 ~/Projects/hol_ghc_app。新建会话时把 Workspace 从 New worktree 改成 Current checkout，对应课程说的「本地文件夹会话」。
  5. 选模式和模型。输入框下方选 Autopilot，模型在 More models 里选 GPT-6 Luna。不要停在 Auto。
  6. 把工具权限设为 Approve all。点 Autopilot → Tool permissions → Approve all。不改的话，Autopilot 下没人点批准，所有命令都会被拒（见 Lab 1 第一轮）。

Lessons

踩坑与取舍

最关键

Autopilot 要配 Approve all

工具权限默认是 Always ask。Autopilot 下没人点批准，命令全部被拒，Agent 只能读代码。

取舍：Approve all 让 Agent 在本仓库里不经确认就跑命令。这是课程「连续执行」的前提；靠提示词里的「只修改 LabN/Code、不要提交」划边界。

仓库信任

选 Skip for now

仓库里没有 hooks、MCP 或扩展配置，不需要信任它；信任会让这些配置以后都能自动运行代码。

注意：不信任时 App 会提示「Tool permissions limited」，但在 Approve all 下命令能正常执行。

锁屏

App 后台照跑，界面操作要解锁

向日葵断开后 Mac 立即锁屏，取不到 App 窗口。解法：解锁时一次性把 Lab 2/3/4 派出去，三个会话改的是不同目录，可以并行；提示词加「不要停下来提问」。

代价：运行中途的进度截图少了，只有「发出时」和「完成后」两张。

工作区

Current checkout 会切回 main

预先开的 run 分支被 App 切回了 main，改动停在 main 的工作区里，没有提交。

要留档的话，先 git switch -c 带着改动开分支再提交。

依赖源

镜像和公共源都能用

README 用的是 packagefeedproxy.microsoft.io。本次 PyPI 和 npm 都改用了公共 registry，版本保持锁定，结果一致。

更正：手册初版写「外部账号连不上这个镜像」，当时没有验证。2026-10-30 实测公网可访问，上游课程的 Pages 工作流也在用它。

副作用

App 改写了 Lab2/README.md

Agent 把 README 里的命令改成了本机 venv 路径和公共源。适合本机复现，不适合合回课程仓库，提交前要回退这个文件。

系统弹窗

Python 请求「本地网络」权限

启动本地服务时 macOS 会弹出这个询问。实验只用 127.0.0.1，选「不允许」也不影响。

规划提问

Plan 模式会停下来问关键选择

Lab 2 规划时，App 问旁白用固定稿还是 SDK 生成。这正是 Plan 的价值：影响实现的决定由人来做。
